# Text Classification on E-commerce Data using FastText

FastText-based multi-class classification for e-commerce product text. Built for noisy product titles/descriptions where typos and rare words are common.

## Overview

This project trains a supervised FastText model on product text to predict category labels. FastText’s subword (character n-gram) embeddings help with misspellings and out-of-vocabulary tokens without requiring a heavy transformer stack.

## Why I Built This

I wanted a practical NLP baseline for e-commerce categorization that trains quickly, runs on a laptop, and stays robust on messy retail text.

## Key Features

- Multi-class product category classification
- Text cleaning / FastText label formatting in a Jupyter notebook
- Subword embeddings for unseen and misspelled tokens
- Fast training and inference relative to deep sequence models

## Getting Started

```bash

cd Text-Classification-on-E-commerce-Data-using-FastText
pip install -r Requirements.txt.txt
jupyter notebook Text_classification_fasttext_ecommerce_dataset.ipynb
```

## Usage

Run the notebook end-to-end. It loads the CSV, prepares FastText-format training data, trains a supervised model, and evaluates predictions.

Example FastText training call (as used in the notebook workflow):

```python
import fasttext

model = fasttext.train_supervised(
    input="train.txt",  # generated by the notebook
    lr=0.1,
    epoch=25,
    wordNgrams=2,
    dim=100,
)
```
